SECCIÓN 6: SISTEMAS OPERATIVOS (UBUNTU 24.04 EN VM)
GUÍA DE COMANDOS Y PASOS PASO A PASO PARA LAS CAPTURAS 26 A 30
================================================================================

--------------------------------------------------------------------------------
1. CREAR ESTRUCTURA DEL PROYECTO (Captura 26)
--------------------------------------------------------------------------------
# Crear la carpeta 'examen', dentro 'aeropuerto', y dentro las subcarpetas: backend, frontend, movil, docs
mkdir -p ~/examen/aeropuerto/{backend,frontend,movil,docs}

# Verificar la estructura generada con el comando tree:
cd ~/examen
tree aeropuerto/

# Salida esperada en terminal:
# aeropuerto/
# ├── backend
# ├── docs
# ├── frontend
# └── movil
# 4 directories, 0 files


--------------------------------------------------------------------------------
2. NAVEGACIÓN Y VERIFICACIÓN (Captura 27)
--------------------------------------------------------------------------------
# Entrar a la carpeta aeropuerto:
cd ~/examen/aeropuerto

# Verificar la ruta actual de trabajo:
pwd
# Salida: /home/tu_usuario/examen/aeropuerto

# Listar el contenido detallado incluyendo archivos ocultos:
ls -la


--------------------------------------------------------------------------------
3. CREAR ARCHIVOS DE EVIDENCIA
--------------------------------------------------------------------------------
# Entrar a la carpeta docs y crear los archivos comandos.txt y evidencia.txt:
cd ~/examen/aeropuerto/docs
touch comandos.txt evidencia.txt

# Registrar la fecha y hora del sistema dentro de evidencia.txt:
date >> evidencia.txt

# Verificar el contenido de evidencia.txt:
cat evidencia.txt


--------------------------------------------------------------------------------
4. REDIRECCIÓN DE SALIDA (Captura 28)
--------------------------------------------------------------------------------
# Guardar la salida del comando who en un archivo (redirección simple con >):
who > salida_sistema.txt

# Agregar la salida del comando ls -la al mismo archivo (redirección de anexado con >>):
ls -la >> salida_sistema.txt

# Verificar el contenido final del archivo:
cat salida_sistema.txt


--------------------------------------------------------------------------------
5. BUSCAR PALABRA DENTRO DE ARCHIVO (Captura 29)
--------------------------------------------------------------------------------
# Escribir el contenido requerido dentro del archivo comandos.txt:
cat << 'EOF' > ~/examen/aeropuerto/docs/comandos.txt
Proyecto Aeropuerto - Backend
GET /api/flights/
GET /api/flights/15/
POST /api/flights/
DELETE /api/flights/10/
INFO: flight created successfully
INFO: flights service running
WARN: flight delay detected
EOF

# Mostrar el contenido completo del archivo:
cat ~/examen/aeropuerto/docs/comandos.txt

# Buscar la palabra 'flights' dentro de comandos.txt:
grep "flights" ~/examen/aeropuerto/docs/comandos.txt

# Buscar mostrando el número de línea (-n):
grep -n "flights" ~/examen/aeropuerto/docs/comandos.txt

# Buscar registros de tipo INFO o WARN:
grep -n "INFO" ~/examen/aeropuerto/docs/comandos.txt
grep -n "WARN" ~/examen/aeropuerto/docs/comandos.txt


--------------------------------------------------------------------------------
6. LOCALIZAR ARCHIVO
--------------------------------------------------------------------------------
# Crear un archivo README.md dentro de backend:
touch ~/examen/aeropuerto/backend/README.md

# Regresar a la carpeta aeropuerto y buscar el archivo README.md:
cd ~/examen/aeropuerto
find . -name "README.md"
# Salida: ./backend/README.md


--------------------------------------------------------------------------------
7. COPIAR Y MOVER ARCHIVOS
--------------------------------------------------------------------------------
# Copiar evidencia.txt para crear un respaldo:
cd ~/examen/aeropuerto/docs
cp evidencia.txt evidencia_respaldo.txt

# Mover el archivo de respaldo a la carpeta backend:
mv evidencia_respaldo.txt ~/examen/aeropuerto/backend/

# Verificar en docs y en backend que el archivo fue copiado y movido:
ls -la ~/examen/aeropuerto/docs/
ls -la ~/examen/aeropuerto/backend/


--------------------------------------------------------------------------------
8. PERMISOS Y STICKY BIT (Captura 30)
--------------------------------------------------------------------------------
# Ver los permisos actuales de la carpeta docs:
cd ~/examen/aeropuerto
ls -ld docs

# Modificar permisos de docs (ejemplo: lectura, escritura y ejecución para usuario y grupo):
chmod 775 docs
ls -ld docs

# Crear carpeta shared dentro de aeropuerto:
mkdir shared

# Aplicar el Sticky Bit (1777: todos pueden leer/escribir pero solo el dueño puede borrar sus archivos):
chmod 1777 shared

# Verificar los permisos y el Sticky Bit (debe mostrar 't' al final: drwxrwxrwt):
ls -ld shared

QUITAR LA CARPETA MOVIL PARA SUBIRLA A GITHUB (DESVINCULAR REPOSITORIO EMBEBIDO)
================================================================================

Configurar git en el proyecto local para poder subir todos los cambios a GitHub.
Comando: git config user.name "User"
Comando: git config user.email "email"
Comando: git remote add origin "url"
Comando: git push -u origin main

QUITAR LA CARPETA MOVIL PARA SUBIRLA A GITHUB
# 1. Quitar la carpeta móvil del índice de git principal (ej: aeropuerto-rn):
git rm --cached -f -r aeropuerto-rn

# 2. Eliminar la carpeta .git interna de aeropuerto-rn
rm -rf aeropuerto-rn/.git

# 3. Volver a agregar todo al repositorio principal
git add .

# 4. Verificar el estado
git status
